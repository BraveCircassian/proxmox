## ✨ Возможности

- 🔄 **Два режима работы**: интерактивный (меню) и автоматический (`--default`)
- 🔐 **Гибкая аутентификация**: поддержка SSH-ключей и/или пароля для Cloud-Init
- 🛡️ **Валидация ввода**: проверка совпадения паролей, предупреждение о слабых паролях
- 📦 **Автоматическая загрузка**: скачивание официального cloud-образа Ubuntu 24.04
- ⚙️ **Полная настройка ВМ**: память, CPU, сеть, хранилище, диск
- 🚀 **Оптимизация диска**: `discard=on`, `ssd=1`, `iothread=1` для лучшей производительности
- 🧩 **Cloud-Init интеграция**: пользователь, сеть, DNS, SSH-ключи, пароль
- 📋 **Конвертация в шаблон**: автоматическое преобразование ВМ в template после настройки
- ✅ **Preflight-проверки**: проверка прав root, наличия `qm` и `wget`

## 🛠 Требования

| Компонент | Требование | Проверка |
|-----------|------------|----------|
| **Proxmox VE** | Версия 7.0+ | `pveversion` |
| **Права доступа** | Запуск от `root` | `id` |
| **Утилиты** | `qm`, `wget` | `command -v qm wget` |
| **Хранилище** | Доступное место на целевом storage | `pvesm status` |
| **Сеть** | Настроенный bridge (по умолчанию `vmbr0`) | `cat /etc/network/interfaces` |

> ⚠️ **Важно**: Скрипт создаёт ВМ с указанным VMID. Убедитесь, что ID свободен в вашем кластере.

## 🚀 Быстрый старт

### 1. Скопируйте скрипт на узел Proxmox

```bash
# Скачайте или создайте файл
nano /root/automation-cloud-image.sh
# Вставьте содержимое скрипта и сохраните

chmod +x /root/automation-cloud-image.sh
```

### 2. Запустите скрипт

```bash
# Интерактивный режим (рекомендуется)
/root/automation-cloud-image.sh

# Или автоматический режим с настройками по умолчанию
/root/automation-cloud-image.sh --default
```

### 3. Используйте шаблон

После завершения в веб-интерфейсе Proxmox:
- Перейдите в **Local (ваш_нод) → Templates**
- Найдите шаблон `ubuntu-24.04` (или заданное имя)
- Кликните ПКМ → **Clone** для создания новых ВМ

```
Proxmox Ubuntu 24.04 Cloud-Init Template Script

2) Customize parameters
3) Exit

```

### Настройка аутентификации

При выборе режима **Customize** скрипт предложит:

1. **SSH-ключ**:
   - Укажите путь к файлу (например, `/root/.ssh/id_rsa.pub`)
   - Или вставьте содержимое ключа напрямую
   - Поддерживаются относительные пути в `~/.ssh/`

2. **Пароль**:
   - Опциональная настройка пароля для пользователя Cloud-Init
   - Подтверждение ввода
   - Предупреждение, если пароль короче 8 символов

> 🔐 **Рекомендация**: Для продакшена используйте **только SSH-ключи**, отключите парольную аутентификацию.

## ⚙️ Конфигурация по умолчанию

| Параметр | Значение | Описание |
|----------|----------|----------|
| `VMID` | `9999` | ID виртуальной машины |
| `VM_NAME` | `ubuntu-24.04` | Имя ВМ в интерфейсе Proxmox |
| `MEMORY_MB` | `1024` | ОЗУ в мегабайтах |
| `CORES` | `1` | Количество vCPU |
| `BRIDGE` | `vmbr0` | Сетевой мост |
| `NET_MODEL` | `virtio` | Модель сетевого адаптера |
| `STORAGE` | `lvm-03` | Целевое хранилище для дисков |
| `CLOUD_DIR` | `/var/lib/vz/template/iso` | Каталог для загрузки образов |
| `CI_USER` | `root` | Пользователь для Cloud-Init |
| `IPCONFIG0` | `ip=dhcp` | Сетевая конфигурация (DHCP) |
| `DISK_RESIZE` | `8G` | Итоговый размер системного диска |
| `SSH_PUBLIC_KEY` | `/root/.ssh/id_rsa.pub` | Путь к публичному SSH-ключу |
| `CI_PASSWORD` | `123123` | Пароль пользователя (смените!) |

## 🔐 Безопасность

### ⚠️ Критические замечания

1. **Пароль по умолчанию** `123123` — **обязательно смените** перед использованием в продакшене!
2. Скрипт выполняется от `root` — убедитесь в доверии к окружению.
3. При передаче SSH-ключа через CLI он может остаться в истории bash:
   ```bash
   # Рекомендация: отключите историю для сессии
   set +o history
   # ...запуск скрипта...
   set -o history
   ```

### Лучшие практики

- ✅ Используйте **только SSH-ключи** в продуктивной среде
- ✅ Ограничьте доступ к скрипту: `chmod 700 automation-cloud-image.sh`
- ✅ Регулярно обновляйте исходный cloud-образ Ubuntu
- ✅ Проверяйте свободные VMID перед запуском
- ✅ Тестируйте шаблон в изолированной среде перед массовым развёртыванием

### Что делает скрипт с данными аутентификации

| Данные | Хранение | Передача |
|--------|----------|----------|
| Пароль | Только в памяти, не логируется | `qm set --cipassword` (шифруется Proxmox) |
| SSH-ключ | Чтение из файла или ввод | `qm set --sshkeys` (обрабатывается Cloud-Init) |

## 🐛 Устранение неполадок

| Проблема | Возможная причина | Решение |
|----------|-------------------|---------|
| `ERROR: Run this script as root` | Запуск не от root | Используйте `sudo` или войдите как root |
| `qm command not found` | Скрипт запущен не на узле Proxmox | Запустите на хосте с установленным PVE |
| `ERROR: VM 9998 already exists!` | VMID занят | Выберите другой ID в интерактивном режиме |
| Ошибка загрузки образа | Нет доступа к интернету / proxy | Проверьте сеть или скачайте образ вручную в `CLOUD_DIR` |
| Шаблон не появляется в UI | ВМ не остановлена перед template | Скрипт делает `qm stop`, но проверьте логи: `tail -f /var/log/pve/tasks/*` |
| Не применяется SSH-ключ | Неправильный формат ключа | Убедитесь, что ключ в формате `ssh-rsa AAAA...` без лишних переносов |

### Просмотр логов Proxmox

```bash
# Логи задач PVE
tail -f /var/log/pve/tasks/*

# Статус ВМ
qm list
qm status <VMID>

# Проверка cloud-init конфигурации
qm cloudinit dump <VMID> user
```

## 🤝 Разработка и вклад

### Как изменить скрипт под свои нужды

1. **Смена образа по умолчанию**:
   ```bash
   # Найдите и отредактируйте:
   UBUNTU_IMG_URL="https://cloud-images.ubuntu.com/releases/24.04/release/ubuntu-24.04-server-cloudimg-amd64.img"
   ```

2. **Добавление параметров Cloud-Init**:
   ```bash
   # Пример: установка hostname через cloud-init
   qm set "$VMID" --ciuser "$CI_USER" --name "$VM_NAME"
   ```

3. **Поддержка других дистрибутивов**:
   - Добавьте переменные для URL и имени файла
   - Расширьте меню выбора дистрибутива

### Тестирование изменений

```bash
# 1. Создайте тестовую ВМ с уникальным VMID
# 2. Проверьте применение параметров:
qm showcmd <VMID>

# 3. Запустите клонированную ВМ и проверьте:
#    - Доступ по SSH
#    - Сетевые настройки
#    - Размер диска
```
