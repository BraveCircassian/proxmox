# Proxmox Ubuntu 24.04 Cloud-Init Template Creator

Bash-скрипт для автоматизированного создания шаблонов Ubuntu 24.04 с поддержкой Cloud-Init в среде Proxmox VE.

## Требования

- Proxmox VE версии 7.0 или новее
- Доступ к узлу Proxmox с правами root
- Утилиты `qm` и `wget`
- Сетевой доступ для загрузки образов Ubuntu

## Установка

Скачайте скрипт:

```bash
curl -fsSL "https://raw.githubusercontent.com/BraveCircassian/proxmox/refs/heads/stage/bash/automation-cloud-image.sh" -o automation-cloud-image.sh
chmod +x automation-cloud-image.sh
```

## Использование

### Интерактивный режим (рекомендуется)

```bash
./automation-cloud-image.sh
```

В процессе выполнения скрипт запросит настройку следующих параметров:
- Параметры ВМ (ID, имя, RAM, CPU, сеть, хранилище)
- Пользователь Cloud-Init и конфигурация сети
- Метод аутентификации (SSH-ключ и/или пароль)

### Режим по умолчанию

```bash
./automation-cloud-image.sh --default
```

Создаёт шаблон с предустановленными настройками без запросов пользователя.

## Конфигурация по умолчанию

| Параметр | Значение | Описание |
|----------|----------|----------|
| VMID | 9999 | ID виртуальной машины |
| VM_NAME | ubuntu-24.04 | Имя шаблона |
| MEMORY_MB | 1024 | Объём оперативной памяти (МБ) |
| CORES | 1 | Количество виртуальных CPU |
| BRIDGE | vmbr0 | Сетевой мост |
| STORAGE | lvm-03 | Целевое хранилище |
| CI_USER | root | Пользователь для Cloud-Init |
| IPCONFIG0 | ip=dhcp | Конфигурация сети |
| DISK_RESIZE | 8G | Итоговый размер системного диска |

## Возможности

- Автоматическая загрузка официального cloud-образа Ubuntu 24.04
- Создание ВМ с оптимизированными настройками (virtio-scsi, iothread, discard)
- Настройка Cloud-Init (пользователь, сеть, DNS, SSH-ключи, пароль)
- Автоматическая конвертация ВМ в шаблон
- Интерактивная настройка параметров
- Подтверждение пароля и проверка его сложности
- Поддержка аутентификации по SSH-ключу

## Замечания по безопасности

- Для продакшена рекомендуется использовать аутентификацию по SSH-ключу
- Минимальная длина пароля — 8 символов (при вводе более короткого выводится предупреждение)
- Скрипт проверяет, что настроен хотя бы один метод аутентификации
- Перед запуском от имени root всегда проверяйте содержимое скрипта

## Алгоритм работы скрипта

1. Предварительные проверки (права root, наличие необходимых утилит)
2. Загрузка cloud-образа Ubuntu (если файл отсутствует)
3. Создание ВМ с указанными параметрами
4. Импорт и настройка диска
5. Подключение Cloud-Init drive
6. Настройка типа ОС, порядка загрузки, агента QEMU
7. Изменение размера диска
8. Применение параметров Cloud-Init (пользователь, сеть, SSH-ключи, пароль, DNS)
9. Остановка ВМ и конвертация в шаблон

## Устранение неполадок

**VM ID уже существует**: Выберите другой VMID в интерактивном режиме

**qm command not found**: Убедитесь, что скрипт запущен на узле Proxmox VE

**Permission denied**: Запустите скрипт от имени root

**Ошибка загрузки**: Проверьте сетевое подключение и настройки прокси
